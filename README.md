# Competitive-Programming

A curated collection of C++ implementations for advanced competitive programming algorithms and data structures, built for speed and correctness under contest conditions.

---

## Contents

### Data Structures

| File                    | Description                                                      |
| ----------------------- | ---------------------------------------------------------------- |
| `Segment Tree.cpp`      | Standard segment tree with point updates and range queries       |
| `Segment Tree Lazy.cpp` | Segment tree with lazy propagation for range updates             |
| `Segment Tree Node.cpp` | Node-based segment tree for complex merge operations             |
| `Sparse Table.cpp`      | O(1) range minimum/maximum queries with O(n log n) preprocessing |
| `PST.cpp`               | Persistent Segment Tree for historical/versioned range queries   |

### Graph & Combinatorics

| File                                  | Description                                                      |
| ------------------------------------- | ---------------------------------------------------------------- |
| `Giant Pizza CSES 2SAT.cpp`           | 2-SAT (2-Satisfiability) solution — CSES Giant Pizza problem     |
| `Painting subarrays DSU Weighted.cpp` | Weighted DSU (Disjoint Set Union) for subarray painting problems |

### Math & Number Theory

| File               | Description                     |
| ------------------ | ------------------------------- |
| `GCD Pair Sum.cpp` | GCD-based pair sum computations |
| `GCD product.cpp`  | GCD product computations        |

### Contest Problems

| File                                | Description                                             |
| ----------------------------------- | ------------------------------------------------------- |
| `Expected Rain Water ICPC 2024.cpp` | Expected value problem from ICPC 2024                   |
| `Maintain Difference a-c=?.cpp`     | Difference maintenance / constraint propagation problem |

---

## Topics Covered

- **Segment Trees** — point/range updates, lazy propagation, persistent variants
- **Sparse Tables** — static RMQ in O(1)
- **DSU / Union-Find** — weighted and path-compressed variants
- **2-SAT** — implication graphs + Kosaraju's / Tarjan's SCC
- **Expected Value** — probabilistic combinatorics
- **Number Theory** — GCD computations and identities
